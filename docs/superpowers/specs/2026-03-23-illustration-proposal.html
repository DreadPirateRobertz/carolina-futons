Phase 8 — LivingSky Wiring Choices
Two wiring targets. Both assets are already built as static SVGs. Phase 8 makes them dynamic — they shift with time-of-day and weather state from LivingSkyState. Stilgar selects approach for each.

4A — Footer Mountain Divider

Currently renders with hardcoded fill colors (#5B8FA8, #5C4033, #3A2518). Three approaches for wiring it to the Living Sky engine. All use LivingSkyState.ridgeColors from living-sky-wix.js.

day (top) → dusk (bottom)
A Tint-only — distant layer shifts

Only the most-distant ridge layer (layer 1) maps to ridgeColors[r4] from LivingSkyState. Middle and front layers remain static espresso/brown. Subtle: day = blue-gray, dusk = warm coral, night = deep indigo.

+ Lowest risk + 1 line of JS − Less dramatic
day → dusk → night
B 3-layer reactive — full depth shift Recommended

All 3 divider layers map to ridgeColors[r4/r3/r1] from LivingSkyState. The whole silhouette shifts warmth with the sky. Day = blue-gray / brown / espresso. Dusk = copper / burnt umber / espresso. Night = deep navy / dark brown / near-black. Mirrors how the header skyline already shifts.

+ Cohesive with header + Same data source − 3 color reads vs 1
sky color overlay tint
C Gradient sky overlay

Keep static SVG layer fills unchanged; add a semi-transparent <rect> overlay that receives the current sky gradient from LivingSkyState. The sky color "washes" over the divider shape.

+ No SVG rebuild − Can muddy the layers − Less true-to-sky

4B — Contact Showroom Scene Wiring

The cabin showroom scene is already fully drawn (contactIllustrations.js, 400×280 static SVG). Three approaches to make it react to LivingSkyState — controlling what time of day the scene feels like.

A Sky gradient swap only

Replace the static #show-sky gradient stop colors with values from LivingSkyState.skyColors (array of hex strings). Everything else stays static. The sky above the mountains shifts; cabin stays the same warm illustration regardless of time.

+ Minimal change + Safe, fast − Cabin stays daytime always
B Full ambient — sky + cabin lighting Recommended

Sky gradient maps to LivingSkyState skyColors array. Cabin window fill tint maps to star presence (state.starOpacity > 0): daylight = window transparent, dusk = soft gold glow, night = warm lantern yellow. Stars appear when starOpacity > 0. Moon arc at night. Ridge layers shift with ridgeColors. The scene feels alive.

+ Deeply coherent with Phase 7 + No new assets needed − More complex JS state reads
C Weather state accent overlay

Sky and cabin stays mostly static, but LivingSkyState.weather triggers accent overlays: rain = diagonal streak SVG pattern at low opacity, fog = gaussian blur on ridge layers, clear = default. Chimney smoke density increases in cold/rain. Seasonal accent only — no ambient light changes.

+ Weather storytelling + Low JS complexity − Doesn't use time-of-day at all

Web SVG rules

  • All SVGs injected as HTML string via $w('#el').html = svg
  • No external references — everything inline
  • Unique gradient/filter IDs per module (prefix: module name)
  • viewBox only — no fixed pixel width/height on root element (use 100%)
  • Colors reference illustrationShared.ILLUSTRATION_COLORS or sharedTokens.colors, never magic strings
  • Tree linework: #2E4A38 (forest-dk) for outlines, #4A7C59 (forest) for fills
  • Mountain linework: #3D6B80 distant, #5B8FA8 mid, #3A2518 near-front
  • Test: seeded PRNG paths must be deterministic (same seed = same ridge)

Mobile SVG rules

  • Use react-native-svg Svg/Path/Rect/Circle/LinearGradient components
  • No CSS — all styles as props (fill, stroke, opacity)
  • CSS animations → Animated API (opacity, transform)
  • CSS linearGradient → RN LinearGradient component
  • viewBox geometry ports directly from web (same path data)
  • dallas confirms: footer divider viewBox 0 0 1440 80 ports as-is
  • dallas confirms: header skyline viewBox 0 0 1040 150 already ported (PR #270)
  • Tree fill: #2E4A38 confirmed aligned with web (PR #269)

LivingSky integration pattern

  • Read state from living-sky-wix.js onMessage handler
  • Key fields: state.ridgeColors (r1–r7, tree), state.skyColors[0] (sky gradient), state.starOpacity (night indicator), state.weather
  • Never poll — subscribe to the #livingSkyFrame postMessage stream
  • Defensive: guard all state reads with null checks — Living Sky may not be initialized on all pages
  • Mobile: subscribe to useLivingSky(totalMinutes) hook, pass state to illustration props
  • skyTable / ridgeTable values: FROZEN — do not change without Stilgar sign-off

Phase 7 Refinement Direction
Blue Ridge aesthetics research: corrected fall palette, haze physics, cloud layer rules, seasonal variants. Drives Phase 8 Living Sky color calibration. Bead: cf-p7r.

Fall Foliage — Corrected Palette

Stagger peak color across ridge layers — foreground trees turn first (gold), background ridges lag 1–2 weeks (still amber). No uniform orange wash.

#D4AF37 Hickory gold (foreground)
#FF8C42 Maple orange
#C85A2A Warm sienna (mid-fall)
#654321 Oak burgundy
#9B7E9B Mauve (serviceberry accent)
#4A7C59 Evergreen retain

Blue Ridge Haze — Physics-Based

Isoprene scatter shifts ridge fill color toward blue at distance. Not an overlay filter — change fill per ridge layer. Near = warm, distant = cool-blue.

#6B8E99 Near (r2)
#7FA8D1 Mid (r4)
#9FB6D4 Far (r6)
#C5D3E0 Distant (r7)

Map to ridgeColors r1–r7 from LivingSkyState. Living Sky tick loop drives the shift automatically.

Cloud Layer Rules

Stilgar rule: NO stormy clouds. Three allowed types:

  • Valley fog — low band under ridgeline; #A8BCC9; opacity 60–80%; blur 8–12px; morning mist in hollows. Most characteristic Blue Ridge feature.
  • Light cumulus — soft white puffs; #F5F5F5; opacity 30–50%; blur 3–5px; scattered, not massed. Summer afternoons.
  • Cirrus wisps — feathery high streaks; #EAECEF; opacity 20–30%; no blur. Fair-weather indicator.

Full Mountain Scene — Swap Criteria

Occasionally replace cabin thumbnail with full panoramic mountain scene. Trigger when ALL conditions met:

  • Scene includes 4+ distinct ridge layers (depth illusion)
  • Valley fog band present (below ridge 2)
  • Dramatic sky: sunset, sunrise, or light cumulus only (no storm)
  • No cabin visible — pure landscape view

Swap trigger: weather === 'clear' AND starOpacity < 0.05 (full daylight). Max frequency: 1 per 6-hour window. Full-scene SVG = separate export in contactIllustrations.js. Bead: cf-p7r.

Technical reference for each illustration component. Defines viewBox, color tokens, animation parameters, and LivingSkyState integration points. Target: implementors working Phase 8 and beyond.

contactIllustrations.js — Contact Showroom Cabin

  • File: src/public/contactIllustrations.js
  • Wix element: #contactShowroomSvg (HtmlComponent, Contact page)
  • ViewBox: 400×280 (preview card: 200×140)
  • GPS pin: teardrop centered above cabin rooftop; CSS drop animation (0.75s cubic-bezier(.36,.07,.19,.97), 0.5s delay); 2 expanding pulse rings (2.2s, ring 2 offset 0.8s delay); direction chevron below pin tip; distance badge (#3A2518 bg, #F2E8D5 text, 0.3 mi)
  • Smoke: 2 staggered ellipses, translateY(-12px) over 3.5s, fade opacity 0.22→0; 1.2s offset; represents active fire = showroom open
  • Cabin detail layers: log-wall texture (3 horizontal strokes), stone base course (#7A5C48), porch overhang + 2 posts, left window (14×11) + right window (16×11) — each with 2 panes + gold glow rect, door panels + divider line + brass handle (cx=95.5), brick chimney (7-wide, 3 mortar rows + vertical half-brick, chimney cap)
  • Phase 8 wiring: sky gradient → state.skyColors array; window glow opacity → driven by state.starOpacity (night >0: 0.5, day 0: 0.17); ridge fills → state.ridgeColors.r4 (far), state.ridgeColors.r1 (near)
  • Night mode trigger: state.starOpacity > 0 → add star circles, brighten window glow, darken cabin fill to #2E1A0A

FooterSection.js — footerMountainDivider

  • File: src/public/FooterSection.js → buildFooterMountainSVG()
  • Wix element: #footerMountainDivider (HtmlComponent, masterPage)
  • ViewBox: 1440×80, preserveAspectRatio="none"
  • Layers: 3 ridge paths + 3 tree silhouettes
  • Static fills: far #5B8FA8 @ 22%; mid #5C4033 @ 40%; near #3A2518 @ 75%

living-sky-component.html — livingSkyFrame

  • File: src/public/living-sky-component.html
  • Wix element: #livingSkyFrame (HtmlComponent, masterPage + home page)
  • State shape: { ridgeColors: {r1,r2,r3,r4,r5,r6,r7,tree}, skyColors: ['#hex',...], starOpacity: 0–1, weather: string }
