## Surprise during authoring

PdpGallery had **one** focus-visible decl on the main zoom-trigger button at line 230, but six other interactive buttons (thumbnail tabs, compare toggle, two spin toggles, the duplicate single-image spin path) relied on browser default focus outlines — works for technically-conformant keyboard nav, but visually inconsistent with the rest of the site's cf-espresso ring system. Single `replace_all` fix because the className shape was identical across the spin variants.

CartTrigger's `aria-label` was already accurate (`"Cart (3 items)"`) but inert at runtime: screen readers only re-announce `aria-label` when the labeled element gains focus. An add-to-cart click triggers a state change in the icon (badge count goes up) but the announcement never fires unless the user happens to Tab back to the cart button. The `aria-live="polite"` sibling span fires on every count change, which is the conventional pattern for cart-add affordances.
