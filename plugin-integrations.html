Plugin Integrations

⚖

Wix MCP

ACTIVE

The backbone. Direct REST API access to our Wix staging site (My Site / halworker85). Every dashboard configuration action goes through this plugin.

  • 🛒 eCommerce setup — installed Wix eCommerce, Stores, Checkout, Cart apps via API
  • 🚚 Shipping config — created delivery profiles, added UPS/USPS/Pickup/Local carriers with fallback rates
  • 🆔 Pricing Plans — created CF+ Monthly ($14.99) and Annual ($119.99) membership plans
  • 🗃 CMS provisioning — created 28 data collections (FAQs, shipping zones, design quiz, etc.)
  • 🔎 App installation — installed eCommerce, Inbox, Pricing Plans, Invoices apps
  • 📊 Marketing tags — Facebook Pixel verified on live site (blocked on staging — not Premium)
🎬

Playwright

ACTIVE

Primary browser driver. Headless Chromium for navigating live/staging sites, taking screenshots, interacting with the Wix editor, and verifying published changes.

  • 📸 Visual verification — screenshot live site to confirm CSS/content changes after publish
  • 💻 Editor automation — Wix Studio editor interactions (documentServices API, element hookup)
  • 🔍 Page snapshots — accessibility tree dumps for element mapping and audit
  • 🛠 Form testing — fill and submit contact forms, test checkout flows
  • 🌐 Navigation testing — verify all nav links, shop dropdowns, footer links resolve correctly
✉

Gmail

ACTIVE

Connected to chrisdealglass@gmail.com (Stilgar's account). Search emails, read threads, draft replies. Used for Wix account management and vendor communication.

  • 📬 Wix notifications — read order confirmations, app install receipts, billing alerts
  • 📝 Draft responses — compose vendor emails (Night & Day Furniture, UPS, etc.)
  • 🔎 Search history — find previous Wix support tickets, account setup emails
  • 🔒 Account recovery — access password reset emails for halworker85 and business accounts
🔬

Serena

ACTIVE

Semantic code intelligence. Understands our Velo codebase structure — symbols, references, relationships. Used for targeted code reading and surgical edits.

  • 🗂 Symbol navigation — find functions, classes, exports across src/ without reading full files
  • 🔗 Reference tracking — find all callers of a function before renaming or changing its signature
  • ✏ Symbolic editing — replace entire function bodies, insert new exports, rename symbols
  • 🗺 Architecture overview — get file-level symbol maps without loading full content
  • 🔍 Pattern search — regex search across codebase for API calls, TODOs, config values
📚

Context7

ACTIVE

Live documentation lookup. Pulls current docs and code examples for any library — Wix SDK, Velo APIs, Node packages. Prevents stale-docs mistakes.

  • 📖 Wix Velo docs — current API signatures for wix-data, wix-ecom, wix-members, etc.
  • 💡 Code examples — working snippets from official docs, tested and versioned
  • 📈 Library discovery — resolve package names → docs with quality scores and snippet counts
  • 🛠 SDK migration — check V2→V3 API changes (e.g., pricing plans schema evolution)

Available libraries: Wix Developers (29,761 snippets), Wix REST API (867), Wix Design System (2,270), Wix Build Apps (3,045)

🤖

Puppeteer

BACKUP

Backup browser driver. Alternative to Playwright for simpler navigation tasks. Used when Playwright's snapshot engine isn't needed or as fallback.

  • 🌐 Simple navigation — load pages, verify HTTP status codes
  • 💻 JS evaluation — run arbitrary JavaScript in page context (useful for Wix editor hacks)
  • 📸 Screenshots — capture page renders for visual comparison
  • 📋 Form filling — fill input fields, click buttons, select dropdowns

How They Work Together

Typical Dashboard Configuration Flow

1 Context7 looks up the current Wix REST API docs for the feature we need
↓
2 Wix MCP calls the API (install app, create plan, add carrier, provision CMS collection)
↓
3 Serena reads our Velo codebase to find where the new IDs/slugs need to be wired in
↓
4 IDs saved to secrets.env → crew writes code → PR merged via GitHub CLI
↓
5 Playwright navigates to the live/staging site to verify the change is working

Editor Hookup Flow (Stilgar in editor, Melania on dashboard)

1 Melania installs apps + creates configs via Wix MCP
↓
2 Stilgar opens Wix Studio editor → assigns element nicknames → wires Velo bindings
↓
3 Playwright takes page snapshot to confirm elements are connected
↓
4 Gmail monitors Wix publish notifications for success/failure
